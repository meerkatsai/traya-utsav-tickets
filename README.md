# Traya Utsav — Chapter 2.0 · Ticket Landing Page

Ticket booking landing page for **Traya Utsav Chapter 2.0** by House of Indiexpo —
Bengaluru's curated festival celebrating conscious living and Made in India brands.

**Event:** 10–11 October 2026 · Jayamahal Palace Exhibition Centre · 12 PM–9 PM

## Stack
- Single self-contained `index.html` — brand fonts (Geometos Neue, Brother 1816), logo and hero collage embedded as base64; no external assets
- Razorpay Checkout wired client-side — set a live Key ID + order-creation endpoint before going live (see comments in `index.html`)
- Responsive: desktop / tablet / mobile with sticky mobile checkout bar
